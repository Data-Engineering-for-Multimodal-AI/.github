# Getting help

- **Something doesn't run.** Check the playbook's README first. Most have a "Tested on" section and an "Expected output" section to compare against. If it still fails, open an issue with the "Bug in a playbook" form and paste the full output.
- **You have a question** about the code, or how a chapter maps to it, open an issue with the "Question" form in that playbook's repository.
- **You found a security problem.** Report it privately. See [SECURITY.md](SECURITY.md).

The playbooks are maintained by one person, so replies can take a few days.

The book: [Data Engineering for Multimodal AI](https://www.oreilly.com/library/view/-/9781098190774/) (O'Reilly, 2026).
